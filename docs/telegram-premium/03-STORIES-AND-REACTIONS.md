# Channel stories, custom reactions, emoji status

These need the channel to reach boost level 1 or higher (`02-BOOSTS.md`). The options appear only when unlocked; **Boosts → Features** in the app lists exactly what each level adds.

## Channel stories (free reach)
1. Open the channel, tap the channel photo (or the menu, **Post Story**), pick a photo or video (1080x1920 works best).
2. Add text and a **link** to `gate.renyxera.workers.dev/pyq/...` with `?utm_source=telegram&utm_medium=story` so sign-ups are tracked.
3. One story a day. Ideas:
   - the vertical film cut, trimmed to 15–30 s
   - the day's question as a picture (I will generate these)
   - Monday: "X days to GATE 2027"
   - Saturday: mock-day banner

## Custom reactions
Channel, Edit, **Reactions**: choose allowed reactions (keep 👍 🔥 🤯 💯 ❤️). Higher levels allow **custom emoji reactions**; add a RENYXERA emoji pack if you want brand reactions.

## Channel emoji status, profile colour, wallpaper (higher levels)
Channel, Edit, **Appearance**: set a profile colour, a logo-pattern background and an emoji status. Use one colour per branch with the same logo so the folder looks like one family.
