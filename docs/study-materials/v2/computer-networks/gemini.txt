### Chapter 00 · Network Fundamentals, Units, Delays & Pipelining *(New Prerequisite Chapter)*

#### Lesson 00.1 · Units (`10^3` vs `2^{10}`), Bandwidth vs Speed & The 4 Network Delays
- **Tag:** `[MUST]` — Without mastering bits/bytes and $T_t$ vs $T_p$, almost every numerical CN question fails immediately (`2026_AN_Q21`, `2022_FN_Q59`, `2017_AN_Q56`).
- **Estimated reading time:** 50 minutes.
- **Prerequisites:** High-school ratios & powers of 10 / powers of 2.
- **Beginner must-see:** Sending a file over a cable is like sending a fleet of trucks through a toll booth onto a highway! **Bandwidth ($B$)** is how wide the toll gate is (`Transmission Delay T_t = FileSize / B`); **Propagation Speed ($v$)** is how fast the trucks drive down the highway (`Propagation Delay T_p = Distance / v`)! Buying a faster 1 Gbps internet plan widens your toll gate (`T_t` shrinks), yet light inside fiber still travels at $2 \times 10^8$ m/s (`T_p` doesn't budge)!
- **Finer points:**
  - **The Golden Unit Rule:**
    - Link bandwidths (`kbps, Mbps, Gbps`) and distances (`km`) ALWAYS use **`10^3, 10^6, 10^9`** (`2026_AN_Q21`, `2018_FN_Q35`, `2017_AN_Q56`).
    - Packet sizes/data (`bytes`, `KB`, `MB`) use **`1 Byte = 8 bits`** (`1 KB = 1024 B` when `2^{10}` is specified for RAM/buffers, or `10^6` when `"million bytes"`/`"1M=10^6"` is stated, `2026_AN_Q21`!).
  - **4 Delays:** Transmission ($T_t = L / B$), Propagation ($T_p = d / v$), Processing ($T_{\text{proc}}$), Queueing ($T_q$).
  - **Bandwidth-Delay Product (`BDP = B × T_p` or `B × RTT`):** "How many bits can be flying mid-air inside the cable right now!" (`2026_AN_Q65`).
  - **Duplex Modes:** Simplex, Half-Duplex, Full-Duplex (`2026_FN_Q18`, `2021_FN_Q42`), and Network Byte Order (**Big Endian**).
- **GATE-level items:** Computing $T_t$ and $T_p$ in ms (`2017_AN_Q56`, `2022_FN_Q59`); converting `MB` to bits using `× 8` (`2026_AN_Q21`).
- **Diagrams needed:** `TIMELINE` / `FLOW` (Highway Toll-Booth analogy showing $T_t = L/B$ vs $T_p = d/v$ + cable filled with $B \times T_p$ bits).
- **Hand traces:** Computing $T_t, T_p$ for `2017_AN_Q56` (`p = 400 ms, q = 50 ms`) and `2022_FN_Q59` (`7.08 ms`).
- **Common mistakes:** Forgetting `× 8` when file is in bytes and bandwidth is in bits/sec (`2026_AN_Q21` gives `8 s` instead of `64 s`!); mixing $10^6$ with $2^{20}$; thinking higher bandwidth reduces propagation delay $T_p$!

#### Lesson 00.2 · Store-and-Forward, Bottleneck Links & Multi-Hop Packet Pipelining
- **Tag:** `[MUST]` — Solves multi-hop transfer delays directly (`2026_AN_Q21`, `2024_FN_Q40`).
- **Estimated reading time:** 45 minutes.
- **Prerequisites:** Lesson 00.1.
- **Beginner must-see:** Routers use **Store-and-Forward**: a router MUST receive the *entire* packet before sending bit #1 out the next link! So sending 1 huge `10^6`-byte file over 2 identical links takes `8 s + 8 s = 16 s` — yet chopping it into `1000` small chunks lets Packet 1 leave Link 2 *while* Packet 2 enters Link 1, cutting total time down to `8.008 s`!
- **Finer points:**
  - **Bottleneck Bandwidth (`2026_AN_Q21`):** When streaming continuously across links $B_1, B_2, B_3$, steady-state throughput is $\min(B_1, B_2, B_3)$!
  - **Equal-Bandwidth Pipelining Formula (`2024_FN_Q40`):** $N$ chunks across $H$ hops (each taking $T_t$): First chunk finishes at $H \cdot T_t + \sum T_p$, remaining $N - 1$ chunks finish one every $T_t$ -> **Total = $(N + H - 1) T_t + \sum T_p$**!
  - **Heterogeneous-Bandwidth Pipelining (`[GATE+]`):** Wait for the bottleneck chunk rate `(N - 1) * T_t(slowest)`!
  - Optimal packet size trade-off (`[SHOULD]`): smaller chunks reduce pipelining delay, yet add more header bytes per chunk!
- **GATE-level items:** Exact pipelined transfer time (`2024_FN_Q40`: `8.008 s` vs `16.000 s`); bottleneck file transfer (`2026_AN_Q21`: `64 s`).
- **Diagrams needed:** `TIMELINE` (1 giant packet `16 s` vs 1000 pipelined chunks `8.008 s` across `P -> Q -> R`, `2024_FN_Q40`); `FLOW` (3 water pipes of widths `2, 0.5, 1` showing `0.5 Mbps` bottleneck, `2026_AN_Q21`).
- **Hand traces:** Tracing 3 chunks of `1000 B` across `P -> Q -> R` (`4 × 0.008 s = 0.032 s`), then scaling to `1000` chunks (`1001 × 0.008 = 8.008 s`, `2024_FN_Q40`).
- **Common mistakes:** Multiplying $N \cdot H \cdot T_t$ when chunks pipeline (`16 s` instead of `8.008 s`, `2024_FN_Q40`); averaging link bandwidths instead of taking `min()` (`2026_AN_Q21`).

### Chapter 02 · Data Link Layer, Link ARQ and MAC

#### Lesson 02.1 · Framing, Hamming Distance, Hamming Code & CRC Polynomial Division
- **Tag:** `[MUST]` — High-frequency 2-mark MCQ foundation (`2026_AN_Q43`, `2021_FN_Q46`, `2021_AN_Q50`, `2017_FN_Q63`, `2017_AN_Q65`).
- **Estimated reading time:** 75 minutes.
- **Prerequisites:** Lesson 01.1, C3 (XOR bitwise operator).
- **Beginner must-see:** Noise on a wire can flip `0` to `1`! Before sending bits, Data Link wraps them inside a **Frame** (so the receiver knows where one message starts and ends) and glues on extra **Check Bits** (like a receipt total!) so the receiver can catch corrupted frames — or even auto-repair 1 flipped bit (**Hamming Code**)!
- **Finer points:**
  - **Framing Methods:** Character/Byte Count (fragile if count corrupts!), Byte Stuffing (`FLAG`, `ESC` before `FLAG`/`ESC`), **Bit Stuffing** (`01111110` delimiter -> insert `0` after 5 consecutive `1`s at sender, delete `0` after 5 `1`s at receiver!).
  - **Hamming Distance ($d_{\min}$) (`2017_AN_Q65`):**
    - Minimum bitwise XOR weight across all pairs of valid codewords.
    - Detect up to **$d_{\min} - 1$** bit errors; Correct up to **$\lfloor (d_{\min} - 1) / 2 \rfloor$** bit errors!
  - **Hamming Error-Correcting Code (`2021_FN_Q46`):**
    - Parity bits $c_1, c_2, c_4, c_8, \dots$ sit at **power-of-2 positions** (`1, 2, 4, 8, ...` from right/LSB!).
    - Minimum parity bits $r$ for $m$ data bits satisfies $2^r \ge m + r + 1$.
    - Computing parity (`c_1` checks bit-index LSB=1: `1,3,5,7,9,11`; `c_2` checks bit 1=1: `2,3,6,7,10,11`; etc.) & syndrome pointing directly to flipped bit position!
  - **1's-Complement Checksum:** Add $k$-bit chunks wrapping overflow carry back to LSB, then invert all bits (`~sum`).
  - **CRC Polynomial Division (`2026_AN_Q43`, `2021_AN_Q50`, `2017_FN_Q63`):**
    - Generator $G(x)$ of degree $r$ (`r + 1` bits): append **$r$ zeros** to data, divide using **XOR (no borrows!)**, replace the $r$ appended zeros with the $r$-bit remainder!
    - CRC error-catching rules: $\ge 2$ non-zero terms catches all 1-bit errors; $(x+1)$ factor catches ALL odd-number bit errors; degree $r$ catches all burst errors of length $\le r$!
- **GATE-level items:** Computing exact CRC check bits (`2026_AN_Q43`, `2021_AN_Q50`, `2017_FN_Q63`), missing check/data bits in 12-bit Hamming codeword (`2021_FN_Q46`), and $d_{\min}$ error-correction limit (`2017_AN_Q65`).
- **Diagrams needed:** `ARRAY` + `FRAMES` (Bit Stuffing inserting `0` after `11111`); `TRACE` (Full XOR long division for `110001011000 ÷ 1001` = `100`, `2026_AN_Q43`); `ARRAY` (12-bit Hamming position ruler `1..12` showing which data bits feed `c_1, c_2, c_4, c_8`, `2021_FN_Q46`).
- **Hand traces:** Tracing `2026_AN_Q43` (`100`), `2021_AN_Q50` (`100`), `2017_FN_Q63` (`101`), `2017_AN_Q65` (`p=3, q=1`), and bit-stuffing `01111110111110`.
- **Common mistakes:** Appending `r + 1` zeros instead of `r` zeros in CRC; borrowing during binary subtraction instead of pure bitwise XOR; converting `x^3 + x + 1` into `111` instead of `1011` (`0*x^2` missing!); checking wrong bit direction in Hamming parity positions.

#### Lesson 02.2 · Link-Layer Flow & Error Control (`Stop-and-Wait`, `GBN`, `SR`, Wrap-Around)
- **Tag:** `[MUST]` — Huge 2-mark NAT generator (`2026_FN_Q45`, `2026_AN_Q65`, `2025_AN_Q36`, `2023_FN_Q17`, `2022_FN_Q59`, `2021_FN_Q42`, `2017_FN_Q56`).
- **Estimated reading time:** 85 minutes.
- **Prerequisites:** Lesson 00.1 ($T_t, T_p$, BDP).
- **Beginner must-see:** Imagine mailing 1 letter (`T_t = 1 ms`) to another city and sitting completely idle for `200 ms` (`2 × T_p`) waiting for a signed receipt before mailing letter #2! That's **Stop-and-Wait** — terrible utilization (`1 / 201 < 0.5%`)! **Sliding Window** fixes this by letting you mail **`W`** letters back-to-back in a pipeline while waiting for old receipts to arrive!
- **Finer points:**
  - **Stop-and-Wait Efficiency (`2025_AN_Q36`, `2023_FN_Q17`, `2017_FN_Q56`):**
    - Ideal (tiny ACK, no errors): $\eta = \frac{T_t}{T_t + 2T_p} = \frac{1}{1 + 2a}$, where $a = T_p / T_t$. (Lowest utilization when $d$ and $B$ are large and $L$ is small, `2023_FN_Q17`!).
    - With $T_{\text{ack}}$, $T_{\text{proc}}$, and header overhead: $\eta = \frac{T_t(\text{useful data})}{T_t(\text{frame}) + 2T_p + T_t(\text{ack}) + T_{\text{proc}}}$ (`2017_FN_Q56`).
    - With frame error probability $p$ (expected transmissions $= \frac{1}{1-p}$): $\eta = \frac{1 - p}{1 + 2a}$!
  - **Sliding Window Utilization & Min Window (`2026_FN_Q45`, `2021_FN_Q42`):**
    - Total cycle time $T_{\text{cycle}} = T_t(\text{data}) + 2T_p + T_t(\text{ack}) + T_{\text{proc}}$.
    - Utilization $\eta = \min\left(1,\ \frac{W \cdot T_t}{T_{\text{cycle}}}\right)$.
    - For $100\%$ utilization: $W \ge \lceil T_{\text{cycle}} / T_t \rceil = \lceil 1 + 2a \rceil$ (`2026_FN_Q45`: $W = 21$)! For target $u\%$ utilization: $W \ge \lceil u \cdot T_{\text{cycle}} / T_t \rceil$ (`2021_FN_Q42` -> `51`).
  - **Go-Back-N (GBN) vs Selective Repeat (SR):**
    - GBN: $W_S \le 2^k - 1$, $W_R = 1$; cumulative ACKs; discards out-of-order frames (`N`-th lost frame resends $k$ frames!).
    - SR: $W_S = W_R \le 2^{k-1}$; individual ACKs + NAK; receiver buffers out-of-order frames (`N`-th lost resends ONLY 1 frame!).
    - **Why $2^k - 1$ vs $2^{k-1}$:** Draw sequence-clock duplicate ambiguity!
  - **Byte-Level Sequence Wrap-Around (`2026_AN_Q65`):** Sequence bits $N$ must cover BOTH $2^N > \text{bytes sent in wrap-guard time } T$ AND $2^N \ge 2 \cdot \text{BDP}$ (or max window)!
- **GATE-level items:** Exact Stop-and-Wait % (`2025_AN_Q36`, `2017_FN_Q56`), min window for 100% / 50% utilization (`2026_FN_Q45`, `2021_FN_Q42`), byte-sequence bits (`2026_AN_Q65`), total transmissions when every $k$-th packet drops (`[GATE+]`).
- **Diagrams needed:** `TIMELINE` (Stop-and-Wait idle gap vs Sliding Window full pipe; Frame #2 loss in GBN vs SR); `FRAMES` (Sequence-clock `0,1,2,3` duplicate-packet failure in SR with `W=3`).
- **Hand traces:** Tracing `2026_FN_Q45` (`W = 21`), `2021_FN_Q42` (`51`), `2025_AN_Q36` (`88.23%`), `2026_AN_Q65` (`30` bits), and counting transmissions for `every 5th frame lost` across 10 frames in GBN (`W=4`).
- **Common mistakes:** Forgetting `ceil()` or `1 + 2a` (giving `20` instead of `21` in `2026_FN_Q45`!); forgetting `× 2` in `2 T_p`; subtracting useful payload header vs full frame inconsistently without checking `2017_FN_Q56`; setting GBN window to $2^k$ instead of $2^k - 1$!

#### Lesson 02.3 · MAC Protocols (`ALOHA`, `CSMA/CD`) & Ethernet Bridging/Switches
- **Tag:** `[MUST]` — Tests classic formulas (`2024_AN_Q36`, `2021_AN_Q32`, `2019_FN_Q62`, `2018_FN_Q65`).
- **Estimated reading time:** 70 minutes.
- **Prerequisites:** Lesson 00.1, Lesson 01.1.
- **Beginner must-see:** When 10 laptops share one cable or Wi-Fi room, if two speak at the exact same moment their signals collide into garbage! **MAC protocols** decide who gets to speak cleanly: either shout randomly and retry (**ALOHA**), listen first then shout and stop immediately if someone clashes (**CSMA/CD**), or plug everyone into a smart **Switch** so nobody shares collisions anymore!
- **Finer points:**
  - **Pure ALOHA vs Slotted ALOHA (`2021_AN_Q32`):**
    - Vulnerable window = $2 T_{\text{fr}}$ (Pure) vs $T_{\text{fr}}$ (Slotted).
    - Poisson load $G = \lambda \cdot T_{\text{fr}}$ (offered frames per frame-time!).
    - Throughput $S = G e^{-2G}$ (max $\frac{1}{2e} \approx 18.4\%$ at $G = 0.5$) for Pure ALOHA; $S = G e^{-G}$ (max $\frac{1}{e} \approx 36.8\%$ at $G = 1$) for Slotted ALOHA. Convert $S \to \text{frames/sec}$ via $S / T_{\text{fr}}$ (`2021_AN_Q32`)!
  - **CSMA Variants & Carrier-Sense Distance (`2018_FN_Q65`):**
    - 1-persistent, non-persistent, p-persistent CSMA.
    - Non-CD carrier sense (`2018_FN_Q65`): if Q senses for $T_{\text{sense}}$ before transmitting, collision is avoided iff P's wave reaches Q before $T_{\text{sense}}$ ends ($d / v \le T_{\text{sense}}$)!
  - **CSMA/CD Minimum Frame Size (`2024_AN_Q36`) & Binary Exponential Backoff:**
    - Sender MUST still be transmitting when worst-case collision wave returns: **$T_t \ge 2 T_p \implies L_{\min} \ge 2 \cdot (d / v) \cdot B$**!
    - IEEE 802.3 Ethernet (`64 B` min frame = `512 bits`, max `1500 B` payload, 48-bit MAC).
    - Backoff after $c$ collisions: wait $K \times 51.2\ \mu\text{s}$ where $K \in \{0, \dots, 2^{\min(c,10)} - 1\}$.
  - **Bridges / Self-Learning Ethernet Switches & Port Counting (`2019_FN_Q62`):**
    - Learning `(MAC, Port)` from source MAC; flooding unknown/broadcast destinations; Spanning Tree Protocol (STP) breaking L2 loops!
    - **Collision Domains vs Broadcast Domains:** Hub = 1 collision domain; Switch = 1 collision domain *per port*, 1 shared broadcast domain; Router = separates broadcast domains!
    - Cascading $k$ $p$-port switches (no dedicated uplink): free host ports = $k \cdot p - 2(k - 1)$ (`2019_FN_Q62` -> $8k - 2(k-1) \ge 15 \implies k=3$)!
  - **Token Ring (`[LATER]`):** Efficiency $\eta = \frac{1}{1 + a/N}$ (Early vs Delayed token release).
- **GATE-level items:** ALOHA frames/sec (`2021_AN_Q32`), CSMA/CD min frame bits (`2024_AN_Q36`), non-CD sensing max distance (`2018_FN_Q65`), cascading switches (`2019_FN_Q62`).
- **Diagrams needed:** `TIMELINE` (Pure ALOHA $2 T_{\text{fr}}$ vs Slotted $T_{\text{fr}}$ collision windows; CSMA/CD $2 T_p$ collision wave vs `2018_FN_Q65` $T_{\text{sense}}$); `GRAPHPIC` (Hub vs Switch vs Router Collision/Broadcast domains + 3 cascaded 8-port switches, `2019_FN_Q62`).
- **Hand traces:** Tracing `2021_AN_Q32` (`G=1 -> 135.3 frames/s`), `2024_AN_Q36` (`500 bits`), `2018_FN_Q65` (`50 m`), `2019_FN_Q62` (`3` switches).
- **Common mistakes:** Plugging $G = 1000$ directly into $G e^{-2G}$ without multiplying by $T_{\text{fr}} = 0.001$ (`2021_AN_Q32`!); using $2 T_p$ instead of $1 \cdot T_{\text{sense}}$ when there is NO collision detection (`2018_FN_Q65`!); subtracting only `1` port instead of `2` ports per switch-to-switch cable (`2019_FN_Q62`!).

### Chapter 03 · IP Addressing, Fragmentation, Support Protocols and Routing

#### Lesson 03.1 · IPv4 Classful/Classless Addressing, Subnetting, VLSM & CIDR Aggregation
- **Tag:** `[MUST]` — Highest Easy/Medium mark-getter in CN (`2026_AN_Q33`, `2026_FN_Q56`, `2024_AN_Q45`, `2022_FN_Q22`, `2022_FN_Q55`, `2020_FN_Q64`, `2019_FN_Q58`).
- **Estimated reading time:** 85 minutes.
- **Prerequisites:** Binary ↔ decimal conversion (`8`-bit octets).
- **Beginner must-see:** An IPv4 address is 32 bits written as 4 byte-numbers (`0..255`). Just like a phone number splits into `(Area Code | Local Number)`, a **Subnet Mask** splits the 32 bits into `(Network Prefix | Host ID)` — and **CIDR (`/N`)** lets ISPs pick ANY cut-point `N` instead of stiff Class A/B/C boundaries, as long as blocks align cleanly on powers of 2!
- **Finer points:**
  - **8-Bit Mask Table:** `/25=.128 (128)`, `/26=.192 (64)`, `/27=.224 (32)`, `/28=.240 (16)`, `/29=.248 (8)`, `/30=.252 (4)`, `/31=.254 (2)`, `/32=.255 (1)`.
  - **Classful Ranges (`A: 0–127`, `B: 128–191`, `C: 192–223`, `D: 224–239`, `E: 240–255`)** & **Special IPs** (Private `10/8, 172.16/12, 192.168/16`, Loopback `127/8`, `0.0.0.0`, `255.255.255.255`).
  - **Host & Subnet Counting (`2026_AN_Q33`, `2019_FN_Q58`, `2022_FN_Q22`):**
    - Total IPs in `/N` = $2^{32-N}$; Assignable hosts/interfaces = **$2^{32-N} - 2$** (first = Network ID, last = Directed Broadcast!).
    - **Counting Subnets in a Topology (`2022_FN_Q22`):** Every isolated LAN segment AND every point-to-point router-to-router link is 1 distinct subnet!
  - **3 Golden Rules of CIDR / Supernetting (`2026_FN_Q56`, `2024_AN_Q45`, `2020_FN_Q64`, `2022_FN_Q55`):**
    1. Size must be a power of 2 (`>= needed hosts + 2` if host subnetting, or `>= needed total IPs`!).
    2. Must sit inside parent ISP range.
    3. **Alignment Rule:** Block start MUST have ALL host bits = 0 (i.e., changing octet MUST be divisible by `BlockSize = 256 - mask_octet`!).
  - **Route Aggregation / Supernetting (`2022_FN_Q55`):** Binary prefix comparison showing when 2+ blocks collapse into 1 prefix vs cannot merge!
  - **VLSM (Variable Length Subnetting):** Always allocate **largest** subnet block first so alignment stays clean!
- **GATE-level items:** Host count from mask (`2026_AN_Q33`), valid aligned `/19` & `/21` CIDR allocations (`2026_FN_Q56`, `2020_FN_Q64`), exact range -> CIDR (`2024_AN_Q45`), enterprise subnet counting (`2022_FN_Q22`), same-subnet check (`2019_FN_Q58`), and multi-prefix route aggregation (`2022_FN_Q55`).
- **Diagrams needed:** `ARRAY` (32-bit binary IP + Mask bitwise AND alignment); `TREE` (Binary CIDR interval splitting `0..255` showing why `84` isn't `/21`-aligned and `164+168` don't merge into `/21`); `GRAPHPIC` (Enterprise topology with every router link/LAN circled as 1 subnet, `2022_FN_Q22`).
- **Hand traces:** Tracing `2026_FN_Q56` (`/19` multiples of 32), `2020_FN_Q64` (`/21` multiples of 8 inside `/17`), `2019_FN_Q58` (`.2, .5, .6` under `/30`), and a 3-department VLSM split.
- **Common mistakes:** Forgetting `- 2` for network/broadcast IPs (`2026_AN_Q33`); forgetting alignment divisibility (`202.17.24.0/19` fails because `24 % 32 != 0`, `2026_FN_Q56`!); forgetting point-to-point router-to-router cables count as subnets (`2022_FN_Q22`!); merging non-sibling blocks (`164 + 168`, `2022_FN_Q55`!).

#### Lesson 03.2 · IPv4 Header, Longest Prefix Match & Multi-Hop Fragmentation (+ IPv6)
- **Tag:** `[MUST]` — Core 2-mark NAT & MSQ generator (`2025_AN_Q18`, `2025_AN_Q23`, `2025_FN_Q40`, `2025_FN_Q57`, `2024_AN_Q29`, `2024_AN_Q30`, `2024_FN_Q43`, `2024_FN_Q58`, `2023_FN_Q65`, `2021_FN_Q22`, `2020_FN_Q29`, `2018_FN_Q64`, `2017_AN_Q27`).
- **Estimated reading time:** 85 minutes.
- **Prerequisites:** Lesson 03.1.
- **Beginner must-see:** Every IP packet wears a 20-byte shipping label (`IPv4 Header`). When a packet hits a narrow bridge (**smaller MTU**), the router chops the data cargo into **Fragments** (measuring start positions in **chunks of 8 bytes**) — and ONLY the final receiver glues those fragments back together!
- **Finer points:**
  - **IPv4 Header Map & Units:**
    - `IHL` (4 bits, **4-byte words**: min 5 = 20 B, max 15 = 60 B -> max Options = `40 B` -> max **Record Route IPs = `9`**, `2017_AN_Q27`!).
    - `Total Length` (16 bits, bytes, max 65,535 B).
    - `Identification` (16 bits, copied to all fragments), `Flags` (`0 | DF | MF`), `Fragment Offset` (13 bits, **8-byte units**!).
    - `TTL` (8 bits, decremented by 1 at every router -> changes `Header Checksum` too! `2024_AN_Q29`, `2020_FN_Q29`).
    - `Protocol` (8 bits: `1 = ICMP`, `2 = IGMP`, `6 = TCP`, `17 = UDP`, `89 = OSPF` — **RIP runs over UDP**, NOT directly over IP! `2025_AN_Q18`).
  - **Longest Prefix Match (LPM) (`2025_FN_Q40`, `2024_FN_Q58`, `2023_FN_Q65`):** Match destination IP in binary against every routing table prefix; pick the **largest `/N`** (longest match), falling back to `0.0.0.0/0` default!
  - **The 5-Step IPv4 Fragmentation Recipe (`2025_AN_Q23`, `2024_FN_Q43`, `2021_FN_Q22`, `2018_FN_Q64`):**
    1. Subtract `IP_hdr` (`20 B`) from `MTU` -> `raw_max_payload`.
    2. **Round DOWN to largest multiple of `8`** (except possibly the final fragment!).
    3. Make sure **TCP/UDP header (`8 B` for UDP, `20–40 B` for TCP) sits INSIDE IP payload** (`2025_AN_Q23` UDP `7488 + 8 = 7496 B`!; only Fragment 0 contains transport port numbers `2021_FN_Q22(D)`!).
    4. Fragmentation happens at source OR any router (`DF=0`); **reassembly ONLY at final destination** (`2024_AN_Q30`, `2020_FN_Q29`); routers do NOT retransmit lost fragments (`2021_FN_Q22(B,C)`).
    5. On 2-hop re-fragmentation (`2024_FN_Q43`), any sub-fragment of a non-final fragment (`MF = 1`) keeps `MF = 1`!
  - **IPv6 Contrast:** Fixed 40-byte header, `128-bit` addresses, `Next Header` (`8` bits, `2018_FN_Q23`), **no router fragmentation** (source does Path MTU Discovery!).
- **GATE-level items:** Multi-hop fragmentation counts (`2024_FN_Q43`, `2025_FN_Q57`), UDP payload + header fragmentation (`2025_AN_Q23`), 3rd fragment offset (`2018_FN_Q64`), LPM packet counting (`2024_FN_Q58`), IPv4 protocol numbers (`2025_AN_Q18`), Record Route max IPs (`2017_AN_Q27`), router field modifications (`2024_AN_Q29`).
- **Diagrams needed:** `MEMORY` (20-byte IPv4 header + 40-byte Options bar with field widths and router-modified highlights); `FRAMES` (2-hop fragmentation `1420 B -> 542 MTU -> 360 MTU` showing `[IP | Payload]`, `MF`, `Offset`, `2024_FN_Q43`); `TRACE` (Binary LPM forwarding table matching `10.1.1.16..205`).
- **Hand traces:** Tracing `2025_AN_Q23` (`7488 + 8 = 7496 -> 116 B`), `2024_FN_Q43` (`3 -> 6` fragments), `2018_FN_Q64` (`offset = 144`), and `2021_FN_Q22` (`620 B`).
- **Common mistakes:** Forgetting `8 B` UDP header inside IP payload (`2025_AN_Q23` gives `108` trap!); forgetting to round payload DOWN to multiple of `8` (`522 -> 520` in `2024_FN_Q43`; `580 -> 576` in `2018_FN_Q64`!); forgetting Fragment 0's `40 B` TCP header doesn't subtract from `4480 B` IP payload (`2018_FN_Q64`!); picking first matching prefix instead of longest `/N`!

#### Lesson 03.3 · IP Support Protocols (`ARP`, `DHCP`, `ICMP`, `IGMP`, `NAT/PAT`)
- **Tag:** `[MUST]` — Guaranteed 1–2 mark Easy/Medium wins (`2026_AN_Q22`, `2025_AN_Q16(i)`, `2024_FN_Q29`, `2021_FN_Q13`, `2019_FN_Q64`).
- **Estimated reading time:** 55 minutes.
- **Prerequisites:** Lesson 01.1, Lesson 03.1.
- **Beginner must-see:** IPv4 needs a team of helpers to actually run on a real LAN: **DHCP** hands out your brand-new IP address by shouting to everyone (`Broadcast`!), **ARP** yells *"Who owns IP `10.0.0.5`? Tell me your MAC card!"* (`Broadcast` Request -> `Unicast` Reply!), **ICMP** sends back *"Host unreachable / TTL expired!"* error notes, and **NAT** lets 50 home devices share ONE public IP!
- **Finer points:**
  - **ARP (`2025_AN_Q16`, `2021_FN_Q13`, `2019_FN_Q64`):** Maps L3 IP -> L2 MAC; Request is L2 **Broadcast (`FF:FF:FF:FF:FF:FF`)**, Reply is **Unicast**; if target IP is outside subnet, host ARPs for **Default Gateway's** MAC (not remote destination's!); ARP Cache TTL; RARP (deprecated) vs Gratuitous ARP.

  - **ICMP & IGMP (`2025_AN_Q18`):** Encapsulated directly inside IP (`Protocol = 1, 2`); `ping` (`Echo Req/Reply`), `traceroute` (incrementing `TTL = 1, 2, 3...` catching `ICMP Time Exceeded`!).
  - **NAT / PAT (`2024_FN_Q29`):** Translates private IP:port <-> public IP:port; outgoing packet modifies **Source IP, Source Port, IP Header Checksum, and TCP/UDP Checksum** (incoming modifies Destination IP/Port/Checksums!).
- **GATE-level items:** Identifying broadcast protocols (`2026_AN_Q22`), ARP Request vs Reply addressing (`2021_FN_Q13`, `2019_FN_Q64`), and NAT header modifications (`2024_FN_Q29`).
- **Diagrams needed:** `TIMELINE` (ARP Request/Reply + DHCP DORA 4-step exchange); `MEMORY` (NAT router table + outgoing IP/TCP header fields highlighted orange).
- **Hand traces:** Tracing ARP for same-subnet vs cross-subnet target; tracing outgoing/incoming NAT packet headers (`2024_FN_Q29`).
- **Common mistakes:** Thinking ARP Reply is ALSO broadcast (`2021_FN_Q13`!); thinking host ARPs for gateway's IP using gateway's IP or remote host's MAC (`2019_FN_Q64`!); forgetting NAT must recompute `Header Checksum` (`2024_FN_Q29(C)`!).

#### Lesson 03.4 · Routing Algorithms (`Flooding`, `Distance Vector`, `Link State`, `RIP`, `OSPF`, `BGP`)
- **Tag:** `[MUST]` — Regularly tested (`2025_AN_Q17`, `2023_FN_Q25`, `2022_FN_Q57`, `2021_AN_Q53`, `2017_AN_Q34`).
- **Estimated reading time:** 70 minutes.
- **Prerequisites:** Lesson 03.2 (and basic graph shortest path intuition).
- **Beginner must-see:** How do routers learn where to send packets? Either routers gossip *"Here is how far I think every city is"* with ONLY their immediate neighbours (**Distance Vector / Bellman-Ford**, like `RIP` — simple, yet suffers bad-news rumours bouncing back as **Count-to-Infinity**!), OR every router shouts its local road map to the ENTIRE city so everyone builds a full map and runs **Dijkstra** (**Link State**, like `OSPF`)!
- **Finer points:**
  - **Static Routing (`2020_FN_Q29(II)`)** & **Flooding** (hop count / sequence numbers prevent infinite flooding).
  - **Distance Vector (`Bellman-Ford` / `RIP`):**
    - Equation: $D_x(y) = \min_v \{ c(x, v) + D_v(y) \}$ (`2021_AN_Q53`!).
    - **Count-to-Infinity Problem & Routing Loop Probability (`2022_FN_Q57`):** When `Q-R` breaks, if `P` tells `Q` *"I can reach R in 2"* before `Q` tells `P` *"R is dead"*, `Q` loops back through `P`!
    - Mitigations: **Split Horizon** & **Poison Reverse** (fix 2-node loops, yet fail on 3+ node loops!), **RIP (`UDP port 520`, max hop `15`, `16 = \infty`)** (`2017_AN_Q34`).
  - **Link State (`Dijkstra` / `OSPF`):**
    - LSA flooding, full topology database at every router, Dijkstra SPF tree.
    - **OSPF (`2023_FN_Q25`, `2017_AN_Q34`):** Intra-domain (same AS), **runs directly over IP (Protocol 89 — NOT TCP/UDP!)**, supports **hierarchical Areas (Area 0 backbone)**.
  - **Inter-Domain Routing (`BGP`):** Path-vector protocol between Autonomous Systems (runs over **TCP port 179**), policy-based routing (avoids loops by storing full AS-PATH!).
- **GATE-level items:** Updating Distance Vector routing table from neighbor vectors (`2021_AN_Q53`); Count-to-Infinity probability (`2022_FN_Q57`); `RIP` vs `OSPF` vs `BGP` transport protocol & algorithm properties (`2025_AN_Q17`, `2023_FN_Q25`, `2017_AN_Q34`).
- **Diagrams needed:** `GRAPHPIC` + `TRACE` (Distance Vector update table for `R -> P, Q` via `X, Y, Z`, `2021_AN_Q53`); `FRAMES` (`P - Q - R` link-cut showing `50%` loop formation when `P` broadcasts before `Q`, `2022_FN_Q57`); `COMPARE` (`RIP vs OSPF vs BGP` full property matrix).
- **Hand traces:** Tracing `2021_AN_Q53` (`R->P = 8 via Y`, `R->Q = 7 via X`); tracing 4 rounds of `P - Q - R` Count-to-Infinity (`2 -> 3 -> 4 -> 5...`).
- **Common mistakes:** Thinking OSPF runs over TCP (`2017_AN_Q34(III)`!) or is inter-domain (`2023_FN_Q25(C)`!); forgetting to add direct link cost `c(R, neighbor)` to neighbor's distance vector (`2021_AN_Q53`!).

### Chapter 04 · Transport Layer, TCP/UDP and Congestion Control

#### Lesson 04.1 · Ports, Multiplexing, UDP & Socket Programming
- **Tag:** `[MUST]` — Covers UDP, ports, multiplexing, and socket API (`2018_FN_Q23(Ports)`, `2017_AN_Q18`).

- **Beginner must-see:** IP delivers a packet to your *building* (your computer); **Transport Layer Ports** (`0..65535`) deliver it to the exact *apartment* (Chrome vs Spotify vs Zoom)! **UDP** is lightweight, connectionless, and keeps each `sendto()` message separate (**8-byte header**); **TCP** builds a reliable, ordered continuous pipe!

    - Blocking `accept()` returns a brand-new connected socket FD per TCP client!
    - **Connected UDP Sockets (`2017_AN_Q18`):** Calling `connect()` on a UDP socket pins ONE remote peer (receives ICMP port-unreachable errors asynchronously; CANNOT talk to multiple peers simultaneously; CAN call `connect()` again to switch peer!).
- **GATE-level items:** 2-tuple vs 4-tuple socket demultiplexing; connected UDP socket behaviour (`2017_AN_Q18`); UDP header fields & port bit width (`16` bits, `2018_FN_Q23`).
- **Diagrams needed:** `MEMORY` (UDP 8-byte header + 2-tuple vs 4-tuple demux buckets); `TIMELINE` (TCP `socket -> bind -> listen -> accept <-> connect` ladder vs UDP `connect()` re-pinning peer, `2017_AN_Q18`).
- **Hand traces:** Tracing 2 Chrome tabs talking to the same web server port `80` using distinct `(Src Port)` 4-tuples; tracing `connect()` called twice on UDP socket (`2017_AN_Q18`).
- **Common mistakes:** Thinking a TCP server creates new port numbers for every accepted client (all share server port `80`, separated by client `Src IP:Src Port`!); thinking `connect()` on UDP performs a 3-way handshake (zero packets sent!) or locks the socket forever (`2017_AN_Q18(II)`).

#### Lesson 04.2 · TCP Header, Byte Wrap-Around, 3-Way Handshake & Connection States
- **Tag:** `[MUST]` — Tested every single year (`2026_FN_Q18`, `2025_AN_Q16(ii)`, `2025_FN_Q22`, `2024_FN_Q23`, `2023_FN_Q50`, `2022_FN_Q60`, `2021_AN_Q14`, `2021_FN_Q20`, `2018_FN_Q35`, `2017_FN_Q12`).
- **Estimated reading time:** 85 minutes.
- **Prerequisites:** Lesson 04.1, Lesson 02.2 (sliding window idea).
- **Beginner must-see:** TCP numbers **every single byte** (not packet!) of your data stream, piggybacks ACKs inside outgoing data (`2025_AN_Q16(ii)`), and shakes hands **3 times** before sending data (`SYN -> SYN+ACK -> ACK`) so both sides agree on starting sequence numbers! And because TCP is **full-duplex**, BOTH client and server can say "I'm done" (`FIN`) independently — even at the exact same time (`2026_FN_Q18`)!
- **Finer points:**
  - **TCP 20-byte Header:** Ports (`16+16`), **Seq# (`32`), Ack# (`32`)**, Header Length (`4` bits in 4-B words, `20..60 B`), Flags (`URG, ACK, PSH, RST, SYN, FIN`), `rwnd` (`16` bits + Window Scale option), Checksum, Urgent Ptr.
  - **Sequence Number Wrap-Around (`2023_FN_Q50`, `2022_FN_Q60`, `2018_FN_Q35`):**
    - Bytes sent in `MSL` = `(B / 8) × MSL`.
    - Minimum sequence bits $N$ satisfies $2^N > (B / 8) \times MSL$ (or $\ge$ for wrap time = $2^{32} \times 8 / B$, `2018_FN_Q35`: `~34.36 s` at `1 Gbps`!).
  - **3-Way Handshake (`2025_FN_Q22`, `2024_FN_Q23`, `2021_AN_Q14`):**
    - Initial seq# `X, Y` chosen randomly (`ISN` avoids stale segments from crashed connections!).
    - `SYN` and `FIN` each consume **1 virtual sequence number** (`SYN-ACK` has `ACK# = X + 1`; pure `ACK` consumes `0`!).
  - **4-Way Teardown, Simultaneous Close & State Diagram (`2026_FN_Q18`, `2017_FN_Q12`):**
    - Normal Close: `FIN` (`FIN-WAIT-1`) -> `ACK` (`FIN-WAIT-2`, `2017_FN_Q12`!) -> peer's `FIN` (`TIME-WAIT` for `2 × MSL`!) -> `ACK`.
    - Simultaneous Close (`2026_FN_Q18(D)`): both send `FIN` -> enter `CLOSING` -> both ACK -> `TIME-WAIT`.
  - **Crash / Reboot & Keepalive (`2021_FN_Q20`):** Without keepalive, passive idle client reading hangs forever; if client sends packet to rebooted server (no matching socket), server sends **`RST`** (NOT `FIN`!).
- **GATE-level items:** Handshake flags & Seq/Ack values (`2025_FN_Q22`, `2024_FN_Q23`, `2021_AN_Q14`), Sequence wrap-around bits/time (`2023_FN_Q50`, `2022_FN_Q60`, `2018_FN_Q35`), `FIN-WAIT-2` state (`2017_FN_Q12`), simultaneous close (`2026_FN_Q18`), server reboot `RST` (`2021_FN_Q20`).
- **Diagrams needed:** `MEMORY` (20-byte TCP header); `TIMELINE` (3-Way Handshake + 4-Way Teardown + Simultaneous Close + Server Reboot `RST` crash); `GRAPHPIC` (RFC 793 TCP State Diagram highlighting `ESTABLISHED -> FIN-WAIT-1 -> FIN-WAIT-2 -> TIME-WAIT`).

#### Lesson 04.3 · TCP Flow Control (`rwnd`), Congestion Control (`cwnd`) & Traffic Shaping
- **Tag:** `[MUST]` — High-yield 2-mark numerical & MCQ staple (`2026_FN_Q44`, `2026_AN_Q58`, `2024_AN_Q58`, `2020_FN_Q62`, `2018_FN_Q24`).
- **Estimated reading time:** 85 minutes.
- **Prerequisites:** Lesson 04.2.
- **Beginner must-see:** TCP protects TWO completely different things: **Flow Control (`rwnd`)** makes sure the sender doesn't overflow the *receiver's RAM bucket*, while **Congestion Control (`cwnd`)** makes sure the sender doesn't jam the *intermediate internet routers*! At every moment, the sender can only have **`min(rwnd, cwnd)`** unacknowledged bytes in flight!
- **Finer points:**
  - **Slow Start (`cwnd < ssthresh`):** Starts at `1 MSS` (unless stated otherwise); adds **`+1 MSS` per ACK received**, which **doubles `cwnd` every RTT** (`2018_FN_Q24`, `2026_FN_Q44`)!
  - **Congestion Avoidance (`cwnd >= ssthresh`):** Adds `MSS × (MSS / cwnd)` per ACK = **`+1 MSS` per full RTT** (linear growth!).
  - **Loss Events (Tahoe vs Reno):**
    - **Timeout (`2024_AN_Q58`):** `ssthresh = max(cwnd / 2, 2 MSS)` and **`cwnd = 1 MSS`** (re-enters Slow Start!).
    - **3 Duplicate ACKs (Fast Retransmit / Fast Recovery):** `ssthresh = cwnd / 2` and **`cwnd = ssthresh`** (enters Congestion Avoidance directly, does NOT drop to `1`!).
  - **Exact Round-Indexing Cheat Rules (`2026_FN_Q44`, `2026_AN_Q58`, `2020_FN_Q62`):**
    - At $t = 0$ (Round 1 / RTT 0): sends `1 MSS` (`segment #1`), reaches `2 MSS` after 1 RTT.
    - Cumulative segments sent *before* round $k$ ($0$-indexed) in Slow Start $= 2^k - 1$; during round $k$, sends segments $2^k \dots 2^{k+1}-1$ (`2026_FN_Q44`: segment `2000` sits in `1024..2047` -> $10 \le t < 11$)!
    - Reaching `ssthresh` (`2026_AN_Q58`: `2 -> 4 -> 8 -> 16 = ssthresh`, Congestion Avoidance starts in **Round 4**!).
  - **Traffic Shaping (`[SHOULD]`):** Leaky Bucket (constant smooth output rate `r`) vs Token Bucket (allows bursts up to capacity `b` at max rate `M`, max burst time $S = \frac{b}{M - r}$).
  - **Nagle's Algorithm & Silly Window Syndrome (`[LATER]`):** Short 3-line conceptual box.
- **GATE-level items:** Computing exact `cwnd` at `t + 60 ms` (`2020_FN_Q62`: `44 KB`) or during `3rd RTT` after timeout (`2024_AN_Q58`: `4 MSS`), rounds to reach Congestion Avoidance (`2026_AN_Q58`: `4`), and transmission start time of segment #2000 (`2026_FN_Q44`).
- **Diagrams needed:** `GRAPHPIC` (Dual-bucket Flow `rwnd` + Network `cwnd` bottleneck `min(rwnd, cwnd)`); `TIMELINE` / `TRACE` (Full sawtooth `cwnd` curve comparing Timeout crash to `1` vs 3-Dup-ACK drop to `ssthresh`); `TRACE` (Round-by-round table aligning `Round # | t (ms) | cwnd (start) | Segs Sent | cwnd (end)`).
- **Hand traces:** Tracing `2026_FN_Q44` (`10 <= t < 11`), `2026_AN_Q58` (`4`), `2024_AN_Q58` (`4`), and `2020_FN_Q62` (`44 KB`).
- **Common mistakes:** Doubling `cwnd` on every ACK *numerically* instead of `+1 MSS` per ACK (`2018_FN_Q24(ii)` trap!); letting `cwnd` exceed `rwnd`; confusing Timeout (`cwnd = 1`) with 3-Dup-ACK (`cwnd = ssthresh`); off-by-one between "after `k` RTTs" and "during `k`-th RTT"!

#### Lesson 05.1 · DNS Hierarchy, Iterative vs Recursive Resolution & Resource Records

#### Lesson 05.3 · Network Security Appendix (`RSA`, `Digital Signatures` & `Birthday Attack`)
- **Tag:** `[LATER]` *(Verify against official GATE 2027 syllabus first — `Part B.1` omits Security, and all 3 PYQs `2019_FN_Q46`, `2017_FN_Q28`, `2017_FN_Q47` are 2019 or earlier; keep modular & self-contained so students don't spend scarce time unless confirmed in syllabus!)*
- **Estimated reading time:** 55 minutes.
- **Prerequisites:** Modular arithmetic (`a mod n`), GCD / Euclidean algorithm.
- **Beginner must-see:** Symmetric encryption uses ONE shared secret key (hard to share safely over the internet!). **RSA (Public-Key Crypto)** uses TWO mathematically linked keys: a **Public key** anyone can see, and a **Private key** ONLY you hold! Lock a box with Bob's **Public** key for secrecy; stamp a document with Alice's **Private** key as an unforgeable **Digital Signature**!
- **Finer points:**
  - **RSA Algorithm (`2019_FN_Q46`, `2017_FN_Q47`):**
    1. Pick two primes $p, q$; $n = p \cdot q$; Euler Totient **$\phi(n) = (p - 1)(q - 1)$**.
    2. Note quick recovery trick (`2019_FN_Q46`!): $p + q = n - \phi(n) + 1$! Solve quadratic $x^2 - (p+q)x + pq = 0$!
    3. Pick public exponent $e$ with $\gcd(e, \phi(n)) = 1$.
    4. Compute private exponent $d$ via Extended Euclidean Algorithm: **$e \cdot d \equiv 1 \pmod{\phi(n)}$** (`2017_FN_Q47`).
    5. Encrypt: $C = M^e \bmod n$; Decrypt: $M = C^d \bmod n$.
  - **Confidentiality vs Digital Signatures (`2017_FN_Q28`):**
    - Signature: Sender signs digest $H(m)$ using Sender's **Private** key.
    - **Birthday Attack vs 2nd-Preimage Attack (`2017_FN_Q28`):** Finding *any* colliding pair $(m, m')$ with $H(m) = H(m')$ takes $O(2^{n/2})$ (Birthday attack); ONLY **Sender `S`** (who owns the private key!) can generate a colliding pair, sign `m`, and later swap `m'` with the same valid signature! Neither `R` nor an outsider has `S`'s private key (`2017_FN_Q28`).
- **GATE-level items:** Factoring $n$ from $(n, \phi(n))$ (`2019_FN_Q46`: `97`), finding $d$ from $(p, q, e)$ (`2017_FN_Q47`: `11`), and who can execute a birthday attack on a signed message (`2017_FN_Q28`).
- **Diagrams needed:** `FLOW` (Encryption with Bob's Public key vs Digital Signature with Alice's Private key); `COMPARE` (Birthday Collision vs Preimage Resistance).
- **Hand traces:** Tracing `2019_FN_Q46` (`p+q = 3007 - 2880 + 1 = 128 -> 31, 97`) and `2017_FN_Q47` (`35 d \equiv 1 \pmod{192} -> d=11`).
- **Common mistakes:** Swapping Public vs Private keys in Digital Signatures; forgetting `+1` in $p + q = n - \phi(n) + 1$ (`2019_FN_Q46`); thinking a third party can exploit a hash collision to forge `S`'s signature (`2017_FN_Q28`).

- **Lesson 04.3 (`Flow/Congestion Control & Traffic Shaping`):**
  1. A TCP flow (`MSS=1 KB, rwnd=64 KB`) hits `cwnd = 24 KB` and encounters **3 Duplicate ACKs** (Fast Recovery, NOT timeout!): compute `cwnd` after `4` more RTTs of error-free ACKs (`NAT`).
  2. A Token Bucket shaper (`r = 2 MB/s`, bucket `b = 10 MB`, max output `M = 12 MB/s`) starts full: how many seconds can it sustain peak `12 MB/s` burst? (`NAT`).
  3. Contrast TCP Tahoe vs TCP Reno behaviour immediately after 3 duplicate ACKs vs after a Retransmission Timeout (`MSQ`).

### Chapter 05 · Application Layer Protocols (& Security Appendix)
- **Lesson 05.1 (`DNS Hierarchy, Iterative/Recursive & Records`):**
  1. Suppose local cache holds the `.in` TLD NS IP while everything else is uncached: how many iterative DNS queries resolve `www.iitb.ac.in`? (`NAT`).
  2. Match `A`, `NS`, `CNAME`, and `MX` records to their roles when resolving mail server `mail.example.com` (`MCQ`).
  3. Compare recursive vs iterative DNS load on Root/TLD servers and caching efficiency (`MSQ`).
- **Lesson 05.2 (`HTTP, FTP & Email`):**
  1. Compute total RTTs (including `2`-tier cached DNS = `1` RTT) to download `1` HTML + `12` small images using `HTTP/1.0` with `4` parallel TCP connections vs `HTTP/1.1` persistent non-pipelined (`NAT`).
  2. Why does `If-Modified-Since` Conditional GET return `304 Not Modified` without the object body, saving bandwidth? (`MCQ`).
  3. Which statements accurately contrast FTP Control (`21`) vs Data (`20`), and SMTP vs POP3 vs IMAP? (`MSQ`).
- **Lesson 05.3 (`Security Appendix [Check Syllabus]`):**
  1. Using RSA with `p = 7, q = 11, e = 13`, compute private key `d` and decrypt ciphertext $C = 2^e \bmod 77$? Better: encrypt $M = 2$ -> $C = 2^{13} \bmod 77$ (`NAT`).
  2. Distinguish symmetric AES, RSA Confidentiality, RSA Digital Signature, and cryptographic hash functions on key usage and non-repudiation (`MSQ`).
