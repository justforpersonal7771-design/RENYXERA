# Release 17 — RENYXERA on the Microsoft Store (Windows app)

*Plan, 22 Oct 2026. The app ships as the existing PWA packaged with PWABuilder (MSIX). No second codebase: Store users run the same site, so every web update reaches them automatically. Cost: the Microsoft Store developer account has been free for individual developers since 2025 — confirm on the Partner Center sign-up page before starting; if it asks for a fee, this release moves to the 🟡 paid backlog.*

## Why
- A Store listing builds trust ("real app"), adds discovery in Windows search/Store, and gives a desktop icon, taskbar pin and Start-menu entry.
- Students preparing on laptops get a full-screen, distraction-free window.
- Payments stay on our site (Razorpay): the Microsoft Store allows non-game apps to use their own commerce.

## Prerequisites (code, me)

### M1 · Upgrade the web manifest (`public/manifest.json`)
- `id: "/"`, `name: "RENYXERA — GATE 2027 Preparation"`, `short_name: "RENYXERA"`, description for all six branches (today it says "GATE CSE").
- `categories: ["education", "productivity"]`, `lang: "en-IN"`, `dir: "ltr"`, `orientation: "any"` (laptops are landscape).
- Icons: separate `purpose: "any"` and `purpose: "maskable"` sets (192, 512) plus Windows tile sizes generated by PWABuilder (44, 50, 150, 310 etc.).
- `screenshots`: at least 3 wide (1280×720+, `form_factor: "wide"`) and 3 narrow (phone) with labels.
- `shortcuts`: Practice, Mocks, AI Mentor, Study Planner, Mistakes (jump list on Windows).
- `display_override: ["window-controls-overlay", "standalone"]` and style the title-bar area (draggable region, safe insets).
- `launch_handler: { client_mode: "navigate-existing" }` so a second launch focuses the window.
- `share_target` (optional): receive a shared link/image to "Ask AI Mentor".
Done when: PWABuilder report card shows all "required" and most "recommended" items green; Edge "Install app" works with the new icons.

### M2 · Desktop polish
- Title-bar overlay layout when installed (`@media (display-mode: window-controls-overlay)`).
- Offline page and "you are offline" banner (exists; verify in the installed window).
- Keyboard shortcuts in exam (N next, P previous, M mark, C clear, Ctrl+K search) documented in a help sheet.
- App Badging API: show due revisions/streak at risk on the taskbar icon (`navigator.setAppBadge`).
- Notifications (Windows toast) for mock reminders via the existing reminders, only with permission.

### M3 · Store-safe content and policies
- Privacy policy URL, terms, support URL/email, age rating (IARC questionnaire: education, no user-generated public content unless community launches).
- No links that bypass Store rules (allowed for non-game apps' own payments; keep pricing honest).

## Owner steps (click by click will be given at that time)
1. Create a Microsoft Partner Center developer account (individual) with the RENYXERA Microsoft account; complete identity verification.
2. Reserve the app name "RENYXERA" (and "RENYXERA GATE" as backup).
3. Copy the Package ID, Publisher ID and Publisher display name from Partner Center → Product identity; send them to me (they are not secrets).

## Packaging and submission (me + owner)
1. pwabuilder.com → enter `https://gate.renyxera.workers.dev` → Package for stores → Windows → fill the three identity values → download the MSIX bundle + `.classic` package.
2. Test: install the sideload package on Windows 10/11, check sign-in (Google OAuth popup), Turnstile, payments, MathJax, offline, notifications, window controls.
3. Partner Center → the reserved app → Start submission: pricing Free, markets India (+ all), category Education, store listing (description, 6+ screenshots 1366×768 or larger, logo, keywords: GATE 2027, GATE CSE, PYQ, mock test), age rating, upload the package, submit for certification (typically a few days).
4. After approval: add "Get it from Microsoft" badge on the website and About page; announce on Telegram hub/Instagram.

## Updates
- Web changes ship instantly (no resubmission).
- Resubmit only when the manifest, icons, start URL or identity change. **A custom domain later changes the start URL → a new package version is needed** (plan it together with the domain move; keep workers.dev redirecting).
